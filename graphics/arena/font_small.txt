// The small font of the Arena: the shapes of Jersey 10 (font_big.png), with vertical strokes of 2 pixels
// and horizontal strokes of 1 pixel.
// `bun run arena-font` in lab/ makes font_small.png and the widths of src/arena/arena_gfx.c from this file.
//
// A cell is 8 pixels wide and 16 rows high, and the game draws only its rows 0 to 12. The capitals use rows 3 to 9, the small letters rows 5 to 9,
// and the descenders rows 10 and 11. The accents of the capitals use rows 0 and 1, of the small letters rows 2 and 3.
//
// A glyph is a header line "<code> <label> <first row> [<width>]", then its rows ('#' is a pixel).
// <code> is the code of the character in charmap.txt, in hex, or the name of an accent.
// The width is the step to the next character. By default, it is the width of the pixels plus 1.
// A line "<code> <label> = <base> + <accent> <row>" puts an accent at the center of the base glyph.
