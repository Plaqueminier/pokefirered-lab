Runs

Les Runs de Bot jouent en même temps, à pleine vitesse et sans son. Changer de Run ne les arrête pas : « Arrêter le Run » arrête le Run montré, avec la fin user stop et un Run record. Le modèle et la limite de coût servent seulement au bot modèle (videz-les pour un bot scripté) : vides, ils prennent le modèle par défaut et LAB_COST_LIMIT (ou 0,50 $).

Principe

          

            
Run
un émulateur qui joue depuis la sauvegarde de départ

            
Bot
décide quoi faire, et agit seulement par le Harness

            
Harness
joue les actions du Bot dans le jeu ; ne décide rien

            
Decision point
le jeu attend une entrée : marche, texte, choix, action de combat…

            
Jeu figé
dans un Run de Bot, le jeu tourne seulement pendant une action (ADR 0002) : même Run, quelle que soit la vitesse du Bot

            
Knowledge level
player : ce qu'un joueur attentif sait · full : en plus, les PV et stats exactes de l'ennemi

            
Run du Viewer
pas de Bot : le clavier ou un replay le joue, en temps réel

Milestones

          

            has-pokemon→first-rival-battle→has-pokedex→badge-1 … badge-8
          

          
Lues dans les flags du jeu. Le but d'un Run est une Milestone.

        

        

          
Fins d'un Run

          

            
goal
la Milestone but est atteinte

            
bot stopped
le Bot s'arrête ou lance une erreur

            
user stop
« Arrêter le Run », après l'action en cours

            
frame budget
plus d'images : 30 000, ou 200 000 pour le bot modèle

            
no progress
200 Decision points sans nouvelle case ni Milestone

          

        

        

          
Run record et Runs en parallèle

          

            Un Run de Bot a un Run record : origine (ROM, graine, sauvegarde), Bot, touches à chaque image, événements et
            résultat. Il est écrit dans lab/runs/ à la fin du Run. Les touches seules rejouent le Run : panneau
            « Replay ».
          

          

            Le Harness joue 4 Runs au plus : le Run du Viewer, et 3 Runs de Bot dans des workers, à pleine vitesse et sans son.
            Un Run de Bot donne le même Run record que seul.
