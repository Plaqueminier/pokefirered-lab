Principle

          

            
Run
an emulator that plays from the Starting save

            
Bot
decides what to do, and acts only through the Harness

            
Harness
plays the actions of the Bot in the game; decides nothing

            
Decision point
the game waits for an input: walk, text, choice, battle action…

            
Frozen game
in a Run of a Bot, the game runs only during an action (ADR 0002): the same Run at any speed of the Bot

            
Knowledge level
player: what a careful player knows · full: also the exact HP and stats of the enemy, and all the maps in the Atlas

            
Atlas
what the Run knows of the world: the maps visited, the cells seen on the screen (15 × 10), the exits taken with their destination, the exits seen, the signs read. At the full level: all the maps

            
Viewer Run
no Bot: the keyboard or a replay plays it, in real time

Run record and parallel Runs

          

            A Run of a Bot has a Run record: origin (ROM, seed, save), Bot, keys at each frame, events and result. It goes to
            lab/runs/ at the end of the Run. The keys alone replay the Run: panel "Replay".
          

          

            The Harness plays 4 Runs at most: the Viewer Run, and 3 Runs of Bots in workers, at full speed and with no sound.
            A Run of a Bot gives the same Run record as alone.
