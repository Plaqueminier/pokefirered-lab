# The Viewer uses Preact, Tailwind, Lucide and native popovers

The Viewer was vanilla TypeScript with ad hoc DOM builders and about 290 lines of CSS inline in `index.html`, and its panels sat in a flex row with fixed widths. To make a design system with components that we can use again and again, and a grid of panels that can grow, the Viewer now uses Preact with JSX for its components, Tailwind v4 for its styles (the `@theme` block holds the design tokens), Lucide for its icons, and the native `popover` and `<dialog>` with `@floating-ui/dom` for hover cards and dialogs. Its animations are CSS only. Bun reads JSX and bundles Tailwind with `bun-plugin-tailwind`, so the Viewer still has no separate build step. We did not keep vanilla TypeScript: each panel would need its own state and render code again. We did not take React or a component library: Preact is 3 kB and has the same API, and a library would bring a look that is not ours. The pure view functions (for example `statsView` and `modelPanelView`) stay the test seam; only the render changes.
